# Bedrock-Werkbank

Ressourcen-Lexikon und Baupläne (Eisenfarm, Handelsstation, Kaktusfarm) für **Minecraft Bedrock Edition 1.26.60** als Web-App fürs iPhone. Nach dem ersten Öffnen läuft sie komplett ohne Internet.

**App öffnen:** https://konterplatte.github.io/bedrock-werkbank/

## Aufs iPhone holen

1. Den Link oben in **Safari** öffnen.
2. Unten auf **Teilen** tippen, dann **Zum Home-Bildschirm**.
3. Die App startet danach im Vollbild wie jede andere App.

Neue Versionen lädt die App von selbst, sobald sie online geöffnet wird.

## Inhalt

- `index.html`: Startseite und Navigation
- `lexikon/`: Ressourcen-Lexikon mit 1.880 Einträgen, darunter alle 42 Verzauberungen
- `bauplaene/`: Baupläne Block für Block
- `sw.js`, `manifest.webmanifest`, `icons/`: Offline-Betrieb und App-Symbol
- `lizenzen.txt`: Lizenzen der Schriften
